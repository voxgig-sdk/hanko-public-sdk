Operation ID: thirdPartyCallback.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | code | query | string | No | The authorization code that can be exchanged for an access token and to retrieve user provider data | | state | query | string | Yes | The state | | error | query | string | No | An error returned from the third party provider | | error_description | query | string | No | The description of the error that occurred (if any) |

GET /thirdparty/auth

Operation ID: thirdPartyAuth.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | provider | query | enum: google, github | Yes | The name of the third party provider to log in with. Only providers enabled in the configuration via the thirdparty.providers option can be used. Requesting an unsupported provider results in a redirect with error details in the location query. | | redirect_to | query | string (base64url) | Yes | Base64url encoded string representing the URL the /callback eventually redirects to after successful login with the third party provider. It must match one of the allowed redirect URLs set in the backend configuration through the third_party.allowed_redirect_urls. |

Responses

307: Redirect to third party provider
