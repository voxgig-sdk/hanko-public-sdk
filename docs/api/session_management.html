Property Type Required Description

claims.audience array of string No The intended audience of the token.
claims.email object No Data about the email address associated with the token's subject, if available.

claims.email.is_verified boolean No Indicates whether the email address is verified.
claims.expiration string (date-time) Yes The timestamp indicating when the token will expire.
claims.issued_at string (date-time) No The timestamp indicating when the token was issued.
claims.issuer string No The entity that issued the token.
claims.session_id string (uuid4) Yes The unique identifier for the session associated with this token.
claims.subject string (uuid4) Yes The unique identifier of the token's subject.
expiration_time string (date-time) No Date-time indicating the expiration of the session. Deprecated, please use claims.expiration instead.
idle_expires_at string (date-time) No Timestamp (in UTC) indicating when the session will expire due to inactivity, assuming no further activity occurs before this time. Only present when idle timeout is configured. The value is capped to the JWT expiration time.
is_valid boolean No Indicates whether the session is valid or not
organizations array of object No The organizations the user belongs to, and the role slugs they hold within each. Computed fresh from the database on every call, not embedded in the JWT, so a role or membership change takes effect immediately on the next validation call rather than only after the session token is reissued. Omitted if the user belongs to no organizations.
