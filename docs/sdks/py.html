Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import os
from hanko_public_sdk import HankoPublicSDK

client = HankoPublicSDK({"apikey": os.environ.get("HANKO_PUBLIC_APIKEY")})
